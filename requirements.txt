# Verified-working dependency stack for mclt-griffin-lim.
#
# >>> REQUIRES PYTHON 3.8-3.10 <<<
#
# The MCLT/STFT backends are abandonware (by Nils Werner) that only run on a pre-2023
# scientific-Python stack. The hard constraints are:
#   * numpy < 1.23  -> `stft` indexes arrays with a *list* of slices, which NumPy turned
#                      into an error in 1.23. (numpy 1.22 also has no wheels for Python
#                      3.11+, hence the Python <= 3.10 requirement.)
#   * scipy < 1.9   -> `stft` uses `scipy.real`, removed from the top-level scipy
#                      namespace in SciPy 1.9.
#   * scipy < 1.13  -> `mdct` imports `scipy.signal.kaiser`, removed in SciPy 1.13
#                      (already covered by scipy < 1.9).
#
# The MCLT/STFT packages (NOT the only "mdct"/"stft" on PyPI):
#   mdct -> https://github.com/nils-werner/mdct   (mdct.fast.mclt / imclt)
#   stft -> https://github.com/nils-werner/stft   (cosine window; (i)spectrogram)
#
# The exact versions below were verified end-to-end (`python test.py`) on Python 3.10.
# matplotlib is intentionally NOT required (the dead `import librosa.display` was removed).

numpy==1.22.4
scipy==1.8.1
numba==0.56.4
librosa==0.9.2
soundfile>=0.12
mdct==0.4
stft==0.5.2
